AI-Powered Cloud Cost Anomaly Detector Using Z-score Method to Detect unsual Cloud Billing Spikes . Build With Python, Pandas, and Streamlit.

##Features 
-Detect unusual cloud billing spike using Z -score start list
-Interactive dashboard build with streamlit 
-Visualize cost trends overload


##TECH STACK 
-Python
-Streamlit
-Pandas
##HOW TO RUN
1.Clone the repo;'git clone https://github.com/123muthukumar9898-ops/cloud-cost-anomaly-detector'
2.Install depentencies:'pip install-r requirements.txt'
3.Run the app:'streamlit run app.py'
